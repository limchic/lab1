# Лабораторная работа №2: Основы ООП и принципы проектирования

## Описание
Реализация иерархии классов на Python, демонстрирующая основные принципы объектно-ориентированного программирования (ООП) и принципы SOLID.

Проект моделирует взаимодействие между человеком (`Person`) и его питомцами (`Pet`). Питомцы представлены абстрактным классом `Animal` и конкретными реализациями: `Turtle` (черепаха) и `Parrot` (попугай).

## Структура проекта
- `pet.py` — абстрактный базовый класс (интерфейс) `Pet`, задающий контракт для всех питомцев
- `animal.py` — абстрактный класс `Animal`, реализующий общее состояние (имя, возраст) и поведение
- `turtle.py` — конкретная реализация черепахи
- `parrot.py` — конкретная реализация попугая
- `person.py` — класс `Person`, демонстрирующий полиморфизм (работает с любым объектом, реализующим `Pet`)
- `main.py` — код, демонстрирующий работу всей системы
